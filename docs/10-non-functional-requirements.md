# Non-Functional Requirements

## Performance
- halaman harus ringan;
- asset dioptimalkan;
- request tidak berlebihan;
- query database efisien.

## Responsiveness
Website harus usable pada:
- mobile;
- tablet;
- desktop.

## Security
- password aman;
- authorization;
- validation;
- protection terhadap common web vulnerabilities.

## Maintainability
- struktur kode jelas;
- naming konsisten;
- dependency tidak berlebihan;
- dokumentasi secukupnya.

## Scalability
Arsitektur harus dapat dikembangkan tanpa overengineering.

## Usability
- navigasi jelas;
- feedback jelas;
- error message mudah dipahami;
- checkout sederhana.

## Reliability
- transaksi harus konsisten;
- stok tidak boleh menjadi negatif;
- konflik penyewaan harus dicegah.

## Accessibility
Pertimbangkan:
- semantic HTML;
- keyboard navigation;
- label form;
- kontras yang memadai;
- alt text pada gambar.

## Compatibility
Uji browser modern yang relevan dan perangkat mobile.
