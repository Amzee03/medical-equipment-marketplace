# Glossary

## Marketplace
Platform yang mempertemukan user dengan produk untuk transaksi.

## Product
Alat medis yang tersedia untuk dibeli atau disewa.

## SKU
Kode unik untuk identifikasi produk.

## Inventory
Informasi mengenai persediaan barang.

## Rental
Transaksi penggunaan alat untuk periode tertentu tanpa perpindahan kepemilikan.

## Order
Catatan transaksi user.

## Cart
Keranjang sementara sebelum checkout.

## Checkout
Tahap konfirmasi transaksi sebelum order dibuat.

## Authentication
Proses memastikan identitas user.

## Authorization
Proses menentukan hak akses user.

## API
Antarmuka yang memungkinkan sistem frontend dan backend berkomunikasi.

## CRUD
Create, Read, Update, Delete.

## ERD
Entity Relationship Diagram untuk memodelkan data dan relasi.

## REST API
Pola API berbasis HTTP yang umum digunakan.

## Responsive
Tampilan yang menyesuaikan ukuran perangkat.

## MVP
Minimum Viable Product, versi awal dengan fitur inti.

## UAT
User Acceptance Testing untuk memastikan sistem memenuhi kebutuhan user.
