# Project Requirements

## 1. Gambaran Umum
Proyek ini adalah web marketplace untuk **penjualan dan penyewaan alat-alat medis**. User dapat membeli atau menyewa alat medis melalui website.

Website harus menyediakan katalog produk, kategori berdasarkan fungsi, detail produk, pembelian, penyewaan, pengelolaan pesanan, dan kontak WhatsApp.

## 2. Tujuan
- Menyediakan katalog alat medis yang terstruktur.
- Memungkinkan user membeli alat medis.
- Memungkinkan user menyewa alat medis.
- Memudahkan pencarian dan pemilihan alat.
- Menyediakan informasi produk yang jelas.
- Menyediakan pengelolaan produk dan transaksi.
- Menyediakan akses kontak WhatsApp.

## 3. Aktor
### User
User dapat:
- melihat produk;
- melihat kategori;
- mencari dan memfilter produk;
- melihat detail produk;
- membeli produk;
- menyewa produk;
- mengelola keranjang;
- melakukan checkout;
- melihat pesanan;
- melihat riwayat transaksi;
- menghubungi WhatsApp.

### Admin
Admin dapat:
- mengelola produk;
- mengelola kategori;
- mengelola stok;
- mengelola harga jual;
- mengelola harga sewa;
- mengelola pesanan;
- mengelola data user;
- mengelola informasi marketplace.

## 4. Kontak WhatsApp
Nomor sementara yang digunakan:
**085894744507**

UI yang diinginkan:
- logo WhatsApp floating;
- posisi pojok kiri bawah;
- ketika diklik, mengarah langsung ke WhatsApp dengan nomor tersebut.

## 5. Kategori Produk
Produk harus dikategorikan berdasarkan fungsi. Contoh:
- Diagnostik: stetoskop, termometer, tensimeter.
- Pemeriksaan Laboratorium: mikroskop, centrifuge, glucometer.

Kategori tambahan dapat dikembangkan berdasarkan kebutuhan marketplace.

## 6. Prinsip Scope
Fitur yang belum diperlukan tidak boleh dipaksakan masuk ke versi awal. Gunakan pendekatan bertahap/MVP.

## 7. Halaman yang diperkirakan diperlukan
- Homepage
- Daftar kategori
- Daftar produk
- Detail produk
- Search/filter
- Keranjang
- Checkout
- Login
- Registrasi
- Profil user
- Riwayat/status pesanan
- Detail pesanan
- Dashboard admin
- Manajemen produk
- Manajemen kategori
- Manajemen stok
- Manajemen pesanan
- Manajemen user
- Halaman kontak/informasi
- Halaman error/404

Daftar final harus divalidasi berdasarkan requirement dan alur sistem.
