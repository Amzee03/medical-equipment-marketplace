# UI/UX Knowledge

## 1. Prinsip Utama
Website harus:
- ringan;
- responsif;
- mudah digunakan;
- memiliki navigasi jelas;
- konsisten;
- dapat digunakan pada desktop dan mobile.

## 2. Sitemap Awal
```text
Homepage
├── Kategori
│   └── Produk
```

## 3. Homepage
Elemen yang mungkin diperlukan:
- navbar;
- logo;
- search;
- kategori;
- produk unggulan;
- produk tersedia untuk sewa;
- informasi layanan;
- CTA;
- kontak;
- footer;
- floating WhatsApp.

## 4. Product Listing
Harus mendukung:
- kategori;
- pencarian;
- filter;
- sorting;
- pagination atau infinite loading jika diperlukan.

Product card minimal:
- foto;
- nama;
- kategori;
- harga beli;
- harga sewa jika tersedia;
- status stok;
- tombol detail.

## 5. Product Detail
Minimal:
- foto;
- nama;
- kategori;
- deskripsi;
- fungsi;
- spesifikasi;
- kondisi;
- stok;
- harga jual;
- harga sewa;
- opsi pembelian;
- opsi penyewaan;
- periode sewa;
- tombol keranjang.

## 6. Responsive Design
Prioritaskan:
- mobile;
- tablet;
- desktop.

Hindari layout yang bergantung pada ukuran layar tertentu.

## 7. UX State
Setiap fitur perlu mempertimbangkan:
- loading;
- empty;
- success;
- error;
- validation;
- unavailable.
