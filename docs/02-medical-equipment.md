# Medical Equipment Knowledge

## 1. Tujuan
Data alat medis harus disusun berdasarkan fungsi agar katalog mudah dipahami.

## 2. Contoh Kategori

### A. Diagnostik
Contoh:
- Stetoskop
- Termometer
- Tensimeter
- Pulse Oximeter

### B. Pemeriksaan Laboratorium
Contoh:
- Mikroskop
- Centrifuge
- Glucometer

### C. Monitoring Pasien
Contoh:
- Patient Monitor
- ECG/EKG
- Pulse Oximeter

### D. Peralatan Terapi
Contoh:
- Nebulizer
- Infusion Pump
- Suction Pump

### E. Peralatan Bedah
Contoh:
- Surgical Scissors
- Surgical Forceps
- Scalpel

Kategori dan produk di atas adalah contoh awal dan dapat disesuaikan dengan katalog nyata.

## 3. Data Produk Minimum
Setiap produk sebaiknya memiliki:
- ID produk
- nama produk
- SKU/kode produk
- kategori
- deskripsi
- fungsi
- merk
- model
- spesifikasi
- kondisi
- foto
- stok
- harga jual
- harga sewa
- satuan
- status aktif/nonaktif

## 4. Data Penyewaan
Produk yang dapat disewa perlu memiliki:
- status dapat disewa;
- harga sewa;
- satuan periode sewa;
- ketersediaan;
- tanggal sewa;
- tanggal kembali;
- aturan pengembalian;
- kemungkinan deposit jika bisnis menetapkannya.

## 5. Catatan Domain
Informasi spesifikasi dan penggunaan alat medis harus berasal dari sumber yang valid ketika katalog nyata mulai dibuat. Jangan mengarang spesifikasi teknis atau klaim medis.

## 6. Status Kondisi
Contoh:
- Baru
- Bekas
- Baik
- Perlu pemeriksaan
- Tidak tersedia

Status final mengikuti aturan bisnis.
