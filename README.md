# Medical Equipment Marketplace

Marketplace jual-beli & sewa alat medis berbasis web.

## Tech Stack

| Layer | Teknologi |
|---|---|
| Frontend | Next.js (App Router), TypeScript, Tailwind CSS |
| Backend | Laravel 12 (API-only), PHP 8.4 |
| Database | PostgreSQL 16+ |
| Payment | Midtrans |

## Struktur Folder

```
medical-equipment-marketplace/
├── frontend/   — Aplikasi Next.js (setup di Tahap 5)
├── backend/    — Laravel 12 REST API (setup di Tahap 4)
└── docs/       — Seluruh knowledge base: requirement, schema, alur aplikasi, business policy
```

---

> Lihat folder `docs/` untuk seluruh dokumentasi requirement, schema, dan alur aplikasi.
